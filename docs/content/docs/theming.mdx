## Colour

The page is a `#f4f4f5` canvas with white cards and `#ececee` hairlines. The primary action is ink black (`--brand`, near white in dark mode). The only vivid colour is `--ember` (`#ff5a00`), kept for small badges: `<Badge variant="ember">`. Re-colour the actions by overriding `--brand`.

```css
:root {
  --brand: #1d4ed8;
  --brand-hover: #1e40af;
  --brand-foreground: #ffffff;
}
```

## Roundness

Every corner derives from `--radius`. The default is `0.875rem` (buttons and inputs); cards use `--radius-card` (`2.25rem`) and badges `--radius-badge`. Set `--radius` to `0` for a sharp look.

```css
:root {
  --radius: 0.5rem;
}
```

## Tailwind utilities

With Tailwind CSS v4 the tokens become utilities automatically: `bg-background`, `bg-surface`, `text-muted-foreground`, `border-border`, `bg-brand`, `text-link`, `rounded-lg`, `shadow-md`. They follow the theme, so `dark:` variants are rarely needed.

```tsx
<div className="rounded-lg border border-border bg-surface p-4 text-muted-foreground shadow-sm">…</div>
```

## Overriding a component

Component styles live in `@layer components`, so your own CSS and Tailwind utilities always win without `!important`:

```tsx
<Button className="rounded-full px-6">Pill button</Button>
```
