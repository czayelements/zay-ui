Getting started

czay-ui is a calm, tonal design system for React: design tokens as CSS variables, accessible components built on Base UI, and ready-made page blocks. Tailwind CSS v4 is optional; it only adds utilities mapped to the tokens.

Install

npm install @czayelements/czay-ui@alpha

React 18.2 or newer is required. The package is in alpha: expect small breaking changes until 0.1 is final.

Import the styles once

With Tailwind CSS v4, in your global stylesheet:

@import "tailwindcss";
@import "@czayelements/czay-ui/styles.css";

Without Tailwind, import the plain CSS files instead (tokens, base layer, components, blocks):

@import "@czayelements/czay-ui/tokens.css";
@import "@czayelements/czay-ui/base.css";
@import "@czayelements/czay-ui/components.css";
@import "@czayelements/czay-ui/blocks.css";

Fonts come from your app: define --font-sans, --font-display and --font-mono (with next/font, its variable option does exactly that). Without them the system font stack is used.

Use components

import { Button, Card, CardTitle, Dialog, DialogTrigger, DialogContent } from "@czayelements/czay-ui";
import { Hero, FeatureGrid } from "@czayelements/czay-ui/blocks";

Static components (Button, Card, Badge …) have no hooks and work in server components. Interactive ones (Dialog, Menu, Tabs …) carry "use client". Every component accepts className and the props of the element it renders.

Plain CSS classes

Each component is a zay- class, so the same look works without React: class="zay-btn zay-btn-primary". Everything is in @layer components, so your utilities and CSS always win.

Dark mode

Add the dark class (or data-theme="dark") to <html>. With next-themes use attribute="class". For a layout without flashes, set the class before first paint (see this site's layout).

Portals

Popups render in a portal. The base layer already makes body a positioned element; if you use your own root wrapper, give it isolation: isolate so popups always stack above the page.
