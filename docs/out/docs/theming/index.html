Theming

Every measurement is a CSS custom property in tokens.css. Re-theme by overriding the semantic tokens after importing the styles; components, blocks and Tailwind utilities all follow.

Colour

Colour is a signal, never decoration: sage for the main action, moss for links and focus. Dark mode redefines the same names.

--background

--surface

--foreground

--border

Make it yours

:root {
  --brand: #f5c26b;           /* the conversion colour */
  --brand-foreground: #1b1d1b;
  --link: #8a5a00;
  --ring: #b87a00;
}
.dark {
  --link: #f0c27a;
}

Shape and type

Radii step through --radius-xs to --radius-xl (4 to 20px); full rounding is only for badges and avatars. The type scale is fluid: text-display, text-h1 to text-h3, text-lead, text-body, text-meta (Tailwind utilities). Weights stay at 400 to 600 so headings are tight and calm.

Conventions

  • No card inside a card. For a recessed block use a plain tinted surface.
  • No small uppercase kicker above a heading: the heading carries its own weight.
  • One saturated colour at a time; accent only for action, links and focus.
  • No pill buttons: full rounding belongs to badges.
