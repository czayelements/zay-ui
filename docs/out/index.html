Base UI
Accessible primitives under the hood

Small on purpose

A system you can read in an afternoon and bend to your brand with a handful of variables.

Accessible by construction

Dialogs, menus, tabs, selects and fields are Base UI components: focus management, keyboard and aria are not an afterthought.

Tokens, not magic numbers

Colour, radius, shadow and type live in CSS variables. Override a few to re-theme everything, dark mode included.

Plain CSS under React

Every component is a zay- class. The same look works in HTML, in other frameworks, on a link. Your utilities always win.

Server-component friendly

Static components have no hooks; only the interactive ones are client components.

Blocks for whole pages

Hero, feature grid, stats, FAQ, footer, status pages: compose a page from sections that already look right together.

Calm by design

Warm paper, hairline borders, one sage accent. Colour is a signal for action, never decoration.

Compose, don't configure

Parts you can assemble, with sensible defaults.
